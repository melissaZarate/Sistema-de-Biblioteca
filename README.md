**📚 Sistema de Biblioteca en Java**

Aplicación de consola desarrollada en Java que permite gestionar libros en una biblioteca.

**🚀 Funcionalidades**
Agregar libros
Mostrar lista de libros
Prestar libros
Devolver libros
Control de disponibilidad

**🧠 Conceptos aplicados**
Programación Orientada a Objetos (POO)
Encapsulamiento
Interfaces (Prestable)
Colecciones (ArrayList)
Separación en capas (model, service, app)

**▶️ Cómo ejecutar**
Clonar repositorio
Abrir en NetBeans o IDE compatible
Ejecutar la clase Main

**📌 Mejoras futuras**
Validación de entradas
Persistencia de datos (archivo o base de datos)
Interfaz gráfica
